# 🌊 Seaside Guest House — Kumta, Karnataka

> *Where the River Meets the Sea*

A modern, fully responsive static website for **Seaside Guest House** — a boutique beachside property in Kumta, Karnataka, located at the confluence of the Aghanashini river and the Arabian Sea, minutes from Om Beach and Gokarna.

---

## 🖼️ Pages

| Page | Description |
|---|---|
| `index.html` | Homepage with hero, amenities, highlights & booking CTAs |
| `rooms.html` | Room types, features, pricing & availability |
| `gallery.html` | Full photo gallery (33+ images) of the property |
| `location.html` | Map, directions, nearby attractions & how to reach |
| `contact.html` | Contact form, WhatsApp & direct booking |

---

## ✨ Features

- **Dark mode** premium design with terracotta & cream color palette
- **Fully responsive** — mobile, tablet & desktop
- **Scroll reveal animations** with staggered entrance effects
- **WhatsApp direct booking** integration
- **Interactive photo gallery** with lightbox
- **Embedded Google Maps** with directions
- **Nearby attractions** — Om Beach, Gokarna, Aghanashini Estuary, mangrove boat rides
- **Local dining guide** with Google Maps links
- **Train & road directions** from major cities (Mumbai, Goa, Bengaluru, Mangalore)
- **Complimentary station pickup** info (Kumta Railway Station — 2 km away)

## 🚀 Running Locally

No setup needed — just open any HTML file directly in your browser:

```bash
# Option 1: Open directly
start index.html

# Option 2: Use VS Code Live Server extension
# Right-click index.html → "Open with Live Server"

# Option 3: Python simple server
python -m http.server 8000
# Then visit http://localhost:8000
```
